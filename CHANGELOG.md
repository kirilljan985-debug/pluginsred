# Changelog — Redmine Progress Bars

## 1.1.0 — 2026-10-26

- Прогрессбар в **карточном представлении** списка проектов (`board`) —
  это представление по умолчанию в Redmine 7; бары теперь видны сразу,
  без переключения вида.
- В табличном представлении (`list`) — колонка «Прогресс» (было в 1.0.0).
- CI: при падении тестов хвост лога выводится в аннотации прогона.
- Совместимость: Redmine 6.0+ (тесты CI на `7.0-stable` и `master`), Ruby 3.2+.

Установка: склонировать в `plugins/redmine_progress_bars`, перезапустить
Redmine. Миграций и гем-зависимостей нет.

## 1.0.0 — 2026-10-22

- Колонка «Прогресс» в списке проектов (`list`): бар, процент, счётчик задач.
- Блок «Прогресс» на странице обзора каждого проекта.
- Расчёт: закрытые задачи = 100%, открытые — по полю «% готовности»;
  учитываются права `view_issues` и видимость приватных задач.
- Локализация ru/en.
